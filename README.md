# Quick Lock

A lightweight Android app that locks the screen with one tap.

## Build on GitHub
1. Create a GitHub repository named `QuickLock`.
2. Upload all files and folders from this project to the repository root.
3. Open the repository's **Actions** tab.
4. Select **Build Quick Lock APK** and click **Run workflow** (or push to `main`).
5. Open the completed workflow run and download the `QuickLock-debug-apk` artifact.
6. Extract it and install `app-debug.apk` on your Android phone.

## First use
1. Open Quick Lock.
2. Tap **Enable Device Admin** and approve the Android system prompt.
3. Tap **LOCK SCREEN** whenever you want to turn off and lock the screen.
4. For use without opening the app: swipe down twice to open Android Quick Settings, tap the pencil/Edit button, find **Quick Lock**, and drag it into your active tiles. Then tap that tile anytime to lock the phone.

Android requires Device Admin permission for this screen-lock action. To uninstall the app later,
first deactivate Quick Lock under Android Settings > Security > Device admin apps.

This project does not request internet access and contains no ads or analytics.
